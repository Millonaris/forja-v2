# 32. REGLA MAESTRA DE FORJA DIETA

> **Las calorías futuras no deben tratarse como cifras fijas.**

Primero se mide el mantenimiento real.

Después:

> **déficit = mantenimiento medido - déficit deseado**

y:

> **superávit = mantenimiento medido + superávit pequeño**

La aplicación debe basarse en tendencias reales, no únicamente en fórmulas.
